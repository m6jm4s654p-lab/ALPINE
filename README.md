# ALPINE

日本語のサイバー調UIを備えた選手向けアプリの操作モックです。

## 機能
- 漫画キャラクター風の男性・女性アバター各50種類
- SAJ競技者番号、氏名、チーム名の選手カード
- アバターとは別に記念写真を1枚保存・差し替え
- YH / B級 / FISのポイントとランキング、3種目推移グラフ
- 競技者番号とアバター番号のQR交換デモ
- 公開URLを含むアプリ紹介QR（GitHub Pages上で自動設定）

成績・選手情報はサンプルです。公式データ接続、本人認証、カメラでのQR読取は未実装です。

データと写真はブラウザーのIndexedDBに保存し、外部に送信しません。別端末への同期はありません。ブラウザーのサイトデータ削除で消去されます。初回読込後、Service Workerによってアプリをキャッシュします。

## 公開
この3ファイルをリポジトリのルートへアップロードし、Settings → Pages → Deploy from a branch → main / (root) を選択してください。

## 検証
100種類の選択、写真保存と再読み込み、FIS表示、QR表示、URL検証、320/390pxレイアウトをブラウザーで確認済みです。

## 素材
アバターはAI生成のオリジナルイラストです。特定作品の公式素材ではありません。QR: qrcode-generator (Kazuhiko Arase, MIT)。Icons: Lucide (ISC)。各ライブラリの著作権表記はindex.html内に含まれます。
