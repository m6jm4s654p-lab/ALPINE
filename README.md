# Yuki-Naka

SAJポイント・選手カード・友達一覧を扱うアプリです。

タイトル画面で選手登録。既存の公開SAJ取得専用API https://snowtech-saj-api.take6583.workers.dev を共用し、各端末が自分と友達のSL / GS / SGを取得します。FISは扱わず、マネージャーの登録情報やチーム保存データは共有しません。

毎週木曜0時（日本時間）を区切りに、起動・画面復帰・表示中1時間ごとの確認で未更新の選手を取得します。閉じている間は取得しません。新規選手は初回取得し、DATAから手動更新できます。失敗時は前回の値を保持し、自動再試行は10分以上あけます。APIキャッシュにより公式公開から遅れる場合があります。

GitHub側の定期取得・データ書き換えは行いません。saj-data.jsonは初回用の2026 No.20（3,967名）。update_saj.pyは初期データ作成の補助スクリプトで定期実行しません。

100背景（かわいい50・クール50）、100アバター、スマホ用アイコンを収録。自分のカード画面のQRは削除し、友達追加画面に表示します。友達追加は、自分のQR・コード表示、カメラによる友達QR読み取り、友達コード入力の3つから選びます。カメラ映像は端末内で処理し、読み取り後・画面移動時・非表示時に停止します。

写真・背景・登録・友達一覧・ポイント履歴は端末内に保存します。写真や背景はAPIに送りません。選手選択は本人認証ではありません。カテゴリが判定できない選手は未確認と表示します。順位は初期リスト2026 No.20の参考集計で最新ポイントの順位ではありません。欠損は「—」表示です。

アイコンは画像生成ツールで制作（深いネイビー、氷色の山、友達とスキーを表すシンボル）。背景は10色×10パターン。QR: qrcode-generator (MIT)、Icons: Lucide (ISC)。

登録・友達ポイント更新・保存・通信失敗時保持・写真・100背景・QR表示範囲・320/390px表示をブラウザーで確認。APIの実応答と公開サイト向けCORSも確認済みです。

都道府県名は未選択が初期値で、北海道から沖縄までの標準順です。都道府県以外の加盟団体は末尾に表示します。登録済みの端末は選手カードから起動します。

交換コードはYN4形式の英数字。ランダムIV付きAES-GCMとBase32で競技者番号の直接表示を避け、入力破損を検出します。アプリに共通鍵が含まれるため、秘匿や本人認証を保証する仕組みではありません。旧AC3コードの読み取りは互換性のため維持します。jsQR 1.4.0 (Apache-2.0)、ライセンスはjsQR-LICENSE.txtに同梱。


## 設定・引継ぎ
タイトルの操作は「登録」のみ。登録済みの起動はカード画面です。右上の設定から、アプリ紹介・引継ぎデータ作成・引継ぎデータ読込・データクリアを選びます。

データクリアはタイトルへ戻ります。この時点では消去しません。登録済みで「登録」を押すと確認し、「はい」で登録・友達・写真・背景・履歴などの端末内データをすべて消去して新規登録へ進みます。「いいえ」はカードへ戻ります。

引継ぎはJSONファイル（最大80MB）に登録、友達、アバター、背景、ポイント履歴、SAJ初期データ、記念写真を収録します。写真を含むためファイルは本人が管理してください。読込は形式・写真を検証後、置換確認を表示し、端末保存全体を単一トランザクションで更新します。中断・キャンセル・不正ファイル・保存失敗では元データを保持します。

全消去の両分岐、端末保存と写真の全消去、引継ぎの保存・復元・再起動、不正ファイル拒否、キャンセル、保存失敗時ロールバックを確認済みです。
