# Yuki-Naka

SAJポイント・選手カード・友達一覧を扱うアプリです。

タイトル画面で選手登録。既存の公開SAJ取得専用API https://snowtech-saj-api.take6583.workers.dev を共用し、各端末が自分と友達のSL / GS / SGを取得します。FISは扱わず、マネージャーの登録情報やチーム保存データは共有しません。

毎週木曜0時（日本時間）を区切りに、起動・画面復帰・表示中1時間ごとの確認で未更新の選手を取得します。閉じている間は取得しません。新規選手は初回取得し、DATAから手動更新できます。失敗時は前回の値を保持し、自動再試行は10分以上あけます。APIキャッシュにより公式公開から遅れる場合があります。

全国・各都道府県内順位用の全選手リストは、GitHub Actionsが毎週木曜6時17分（日本時間）に公式の男女小数点リストを取得してsaj-data.jsonを更新・公開します。初回はworkflow_dispatchでも実行できます。GitHub PagesのSourceをGitHub Actionsに設定してください。取得・検証失敗時は公開を中止し、前回のサイトを保持します。公式公開、Actionsの待機・実行、Pages公開まで時間差があります。アプリは起動時、画面復帰・表示時（最短1時間間隔）、DATAの手動更新時に公開済みリストを再取得します。保存済みリストより古いリストは適用しません。取得から24時間以上経過した公開リストは注意表示します。

100背景（かわいい50・クール50）、100アバター、スマホ用アイコンを収録。自分のカード画面のQRは削除し、友達追加画面に表示します。友達追加は、自分のQR・コード表示、カメラによる友達QR読み取り、友達コード入力の3つから選びます。カメラ映像は端末内で処理し、読み取り後・画面移動時・非表示時に停止します。

写真・背景・登録・友達一覧・ポイント履歴は端末内に保存します。写真や背景はAPIに送りません。選手選択は本人認証ではありません。カテゴリが判定できない選手は未確認と表示します。全国・各都道府県内順位は全選手と自分を同じ取得リストに揃えて集計します。基準リスト番号・取得日時と「順位用pt」を表示し、個人APIの「所持pt」と区別します。欠損は「—」表示です。

アイコンは画像生成ツールで制作（深いネイビー、氷色の山、友達とスキーを表すシンボル）。背景は10色×10パターン。QR: qrcode-generator (MIT)、Icons: Lucide (ISC)。

登録・友達ポイント更新・保存・通信失敗時保持・写真・100背景・QR表示範囲・320/390px表示をブラウザーで確認。APIの実応答と公開サイト向けCORSも確認済みです。

都道府県名は未選択が初期値で、北海道から沖縄までの標準順です。都道府県以外の加盟団体は末尾に表示します。登録済みの端末は選手カードから起動します。

交換コードはYN4形式の英数字。ランダムIV付きAES-GCMとBase32で競技者番号の直接表示を避け、入力破損を検出します。アプリに共通鍵が含まれるため、秘匿や本人認証を保証する仕組みではありません。旧AC3コードの読み取りは互換性のため維持します。jsQR 1.4.0 (Apache-2.0)、ライセンスはjsQR-LICENSE.txtに同梱。


## 設定・引継ぎ
タイトルの操作は「登録」のみ。登録済みの起動はカード画面です。右上の設定から、アプリ紹介・引継ぎデータ作成・引継ぎデータ読込・データクリアを選びます。

データクリアはタイトルへ戻ります。この時点では消去しません。登録済みで「登録」を押すと確認し、「はい」で登録・友達・写真・背景・履歴などの端末内データをすべて消去して新規登録へ進みます。「いいえ」はカードへ戻ります。

引継ぎはJSONファイル（最大80MB）に登録、友達、アバター、背景、ポイント履歴、SAJ初期データ、記念写真を収録します。写真を含むためファイルは本人が管理してください。読込は形式・写真を検証後、置換確認を表示し、端末保存全体を単一トランザクションで更新します。中断・キャンセル・不正ファイル・保存失敗では元データを保持します。

全消去の両分岐、端末保存と写真の全消去、引継ぎの保存・復元・再起動、不正ファイル拒否、キャンセル、保存失敗時ロールバックを確認済みです。


## ミッションとRANK！
自分以外の重複しない友達数が5人でライバルモードと下部RANK！、10人でSR背景5種、20人でSSR背景3種を解放します。自分のカード下部に3つのミッションと進捗を表示し、未達成の報酬は？？？です。到達時（既存データは初回起動時）に解放アナウンスを表示し、既読状態を保存します。

RANK！画面で友達を複数指名し、自分と選んだ友達のSL・GS・SGを小さいポイント順に比較します。同点は同順位（1,1,3）、欠損は順位なし。性別・カテゴリを問わず比較し、個別のリスト・取得日時を表示します。公式順位ではありません。

SRはアイスホロ・ローズクォーツ・サンライズ・エメラルド・アメジスト、SSRはレインボークラウン・ゴールデンノヴァ・ギャラクシー。ホログラム・箔・光線・輝点をCSSで表現しています。背景は合計108種です。選択ライバル・背景・解放通知済み状態を引継ぎファイルにも収録します。


## 画面レイアウト
タイトルの成長コピーを削除し「Yuki-Nakaを登録してはじめましょう」に変更。カード見出し右側にアバター・背景選択を配置。画面はビューポート高の固定枠とし、中央mainだけ縦スクロール、下部4/5ボタンは固定位置です。ピンチ・ジェスチャー・Ctrlホイール等のアプリ内ズームを抑止しますが、OSやブラウザーの強制拡大機能までは制御できません。
新規登録・全消去後のアバターは未選択（null）。選択済みは保存・復元します。未選択の交換コードではアバター値255を使用し、現行版で読込・引継ぎ可能です。

SSR背景は生成したホログラム画像を使用したゴールド・シルバー・レインボーの3種に更新。カードの『傾きできらめく』から動きの検知を有効化できます。生成プロンプト・素材・動作についてはSSR-DESIGN.mdを参照。友達コード欄の指定の裏コードで、友達数を変更せずミッションを全解放できます。全解放状態は保存・引継ぎされ、全データクリアで解除されます。

## 管理者向け端末数集計
Supabase Edge Functionとアクセス制限付きDBで、ブラウザー単位の累計端末数を集計します。友達コード入力欄で管理者コードを送信すると、サーバー側で照合し、合計のみ表示します。管理者コード・秘密鍵は公開コードに含みません。設定手順と集計の限界は`SUPABASE-SETUP.md`を参照してください。

## 一般選手の順位
全国・各都道府県内順位は同性内で計算します。K2選手はK2内、一般選手はK2を含む全選手を対象とします。snowtech-team-managerの所属選手向け順位APIを参考にしています。

友達一覧の更新修正：公開リストの更新時、自分と友達のポイント・シーズン・リスト番号・公式データ取得日時を同期します。より新しいリストの保存値は保持します。友達一覧の「最新データを確認」から公開リストと個別APIの両方を手動更新できます。全国・各都道府県内順位は同じ公開リストを使用し、各都道府県内は県連盟で絞ります。
