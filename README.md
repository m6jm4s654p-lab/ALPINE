# Yuki-Tomo

アルペンスキー選手のSAJポイント・選手カード・友達一覧を扱う独立Webアプリです。

## 今回の機能
- SAJ公式公開ポイントリストから県（加盟団体）・性別・氏名・競技者番号で検索し、タイトル画面から自分を登録
- 自分と友達のSL / GS / SGポイント、リスト番号、取得日時を表示
- カード背景100種類（かわいい50・クール50）、男女各50のアバター、端末内の記念写真
- 自分のカード画面にQRは表示せず、友達追加画面にのみ交換QRを表示
- iPhoneホーム画面アイコン、Webアプリマニフェスト、オフライン時の前回データ表示

## SAJデータと更新
`update_saj.py` はSAJ競技データバンクのポイントカレンダーから公開済みの最新リストの男女別「実数型」ZIPを取得します。SAJ_SL / SAJ_GS / SAJ_SGだけを出力し、FISポイント、生年月日、FIS番号は配信しません。

7月で切り替わる当該シーズンに公開ファイルがなければ前シーズンを使用し、画面には実際のデータシーズンとリスト番号を表示します。2026-09-30の初回取得は2026シーズンNo.20、男女計3,967名です。「最新」は取得できた公開リストを意味します。

`.github/workflows/saj-pages.yml` が毎週木曜日06:17（日本時間、GitHubの混雑により遅延あり）、mainへの更新時、手動実行時にSAJを確認し、検証後にデータを保存してGitHub Pagesを公開します。GitHub PagesのSourceはGitHub Actionsを選択します。GitHubの仕様で長期間更新のない公開リポジトリのスケジュールが停止した場合はActions画面で再有効化します。

取得失敗・形式変更・異常な件数減少・古いリストへの後退時は既存ファイルを上書きしません。処理失敗はActionsに記録し、前回データを継続公開します。アプリは起動時、表示復帰時（確認から1時間経過後）、表示中1時間ごと、手動の「最新データを確認」で配信済みデータを確認します。アプリを閉じていてもサーバー側の週次処理は動作します。端末通信失敗は前回データを保持します。

## 表示の意味と制限
- サンプルのYH/B級/FIS切替を廃止し、取得元に対応するSAJポイント表示に統一
- 県内・全国順位は、取得したリストの同性・同カテゴリ内で計算するアプリ集計。SAJ公式順位ではなく、未確定の地域ブロック順位は表示しません。同ポイントは同順位（1,1,3方式）、欠損値は対象外
- K2は既存マネージャーと同じ年齢区分（中学生＋高校1年早生まれ）。それ以外は「一般」。配信に生年月日は含めません
- 推移グラフは、この端末で自分について取得したリスト別の履歴。過去の架空データは使いません
- 選手選択は本人認証ではありません。SAJリスト未掲載の選手は登録できません
- 友達追加はQR文字列入力に対応。カメラからの直接読取は未実装
- QR形式は既存の `AC3:競技者番号:アバター番号` を維持。背景・写真は相手に送信しません
- 写真・背景・選手登録・友達一覧はこのブラウザー内に保存。他端末には同期せず、サイトデータ削除で消えます

## 独立性と素材
取得方式・週次更新方針は `m6jm4s654p-lab/snowtech-team-manager` を参考にし、ALPINEリポジトリ内で独立実装しています。マネージャーのWorkerやチーム情報には接続しません。旧版の保存領域名はデータ維持のため継続使用します。

アイコンは組み込み画像生成ツールで制作。プロンプト要旨：深いネイビーに氷色の山と、友達・スキーの軌跡を表すY字のシンボル。アバターもオリジナルAI生成素材。背景は10色系統×10パターンの100デザインです。
QR: qrcode-generator (Kazuhiko Arase, MIT)。Icons: Lucide (ISC)。ライブラリの著作権表記はindex.htmlに収録。

## 検証
